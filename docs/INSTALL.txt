Clipline 1.1.4 — macOS 14+ / Apple Silicon and Intel

Install: drag Clipline.app to Applications, then launch it.
If macOS blocks the first launch: System Settings → Privacy & Security → Clipline → Open Anyway.
This shared build uses an ad-hoc signature and is not notarized by Apple.

Menu-bar paperclip: open settings. Control + Option + T: show or hide the shelf.
Since 1.1.2, if screenshots are saved directly to Desktop during initial setup,
Clipline creates Desktop/Screenshots (named 截圖 on Chinese-language systems)
and saves new screenshots there. Existing custom locations are preserved.
Old screenshots are not moved. This folder setting remains after quitting Clipline.
Screenshot monitoring retries if folder access is temporarily unavailable and
reconnects when the watched folder is replaced. Allow screenshot-folder access
when macOS asks; an app update may prompt again.
Click a card to open it. Right-click → Copy to copy it.
Press and hold an image for Markup; other card types have no long-press action.
Dragging delivers images and files as files, full text as text, and links as URLs.
Text cards show a summary; copying and dragging preserve the full text.
Cards have a consistent height. Images fit fully without cropping.

Hang copied items is enabled by default. It collects newly copied images,
plain text, HTTP(S) links, and file references. These content types are supported;
not every clipboard format from every app is preserved.
Turn it off in the menu bar to pause collection. Protected clipboard markers
are skipped, but Clipline cannot identify every confidential item.
Pause collection before copying sensitive content.
Contents are saved locally and restored after restarting. Clipboard-generated
contents are stored in:
~/Library/Application Support/Clipline/Clipboard
External files retain references to their originals. The shelf has 3–12 slots,
depending on screen width. When full, the oldest card drops off.

Hover reveal uses only the MacBook notch's width at the top of the display,
derived from its hardware auxiliary-area boundaries. Displays without a notch
use a centered 180-point top region. The hover delay is about 0.08 seconds.
After a hover reveal, leaving the display's upper third closes the shelf immediately.
Idle new screenshots or clipboard items preview for 3 seconds. Holding a card,
dragging, or using a context menu postpones dismissal.
After a manual reveal, enter the shelf and then leave it; it closes 5 seconds later.

Managing the screenshot location is optional. With Handle screenshots enabled,
screenshots are saved to ~/Library/Application Support/Clipline/Screenshots.
Clipline disables macOS floating thumbnails and restores your previous settings
when this option is disabled or the app quits normally.
If screenshots appear only after the bottom-right macOS thumbnail disappears,
press Command + Shift + 5 → Options and disable Show Floating Thumbnail.
This keeps your save location and avoids delayed file writing; Clipline's own
new-item preview still lasts 3 seconds.
Clicking the cross on a screenshot in the private screenshot inbox sends it to
Trash. Removing an external file reference removes its card and preserves the file.
