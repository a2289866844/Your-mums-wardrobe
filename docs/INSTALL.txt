Clipline 1.2 developer preview — macOS 15+ / Apple Silicon and Intel

Developed and maintained by @a2289866844.
Based on Tendedero by Alejandro Buján; independent modified build.

This source preview is separate from the published 1.1.6 installer.
Build with Swift 6: swift test, then scripts/build-app.sh.
A locally packaged app can be dragged into Applications and launched.
The shared build uses an ad-hoc signature and is not notarized by Apple.
If macOS blocks it, use System Settings → Privacy & Security → Open Anyway.
Allow screenshot-folder access when macOS asks.

Control + Option + T: show or hide the shelf.
Command + Shift + V: open history search.
Hover near the notch/top-center edge to reveal cards.
The shelf displays up to six cards per page and 120 recent items.
Search queries the archive, with up to 200 matches including Chinese/OCR text.
OCR runs in the background; a new image may not be searchable immediately.

Copy uses the full content; Copied confirms success and Retry allows another try.
Click a text card to view or edit it. Images open in the system default app.
Right-click for pinning and available text-copy options.
Drag cards into other apps as full text, URLs or file representations.
New items preview for about three seconds; holding, dragging, menus and
editing protect the interaction from automatic dismissal.
Idle card sway and sounds remain available.

Hang copied items is enabled by default; turn it off to pause collection.
Protected clipboard markers are skipped, but cannot identify every secret.
Pause collection before copying sensitive content.

History uses unencrypted SQLite in:
~/Library/Application Support/Clipd
Generated clipboard files use:
~/Library/Application Support/Clipline/Clipboard
External file cards reference their originals. The recent-card limit does
not delete older archive records. This preview does not automatically convert
an existing encrypted Clipd archive; it requires separate offline conversion
with the original key and a verified backup. See the integration documentation.

The preview follows the screenshot save folder configured in macOS.
It does not include Markup, Preview-window centering, screenshot takeover,
sequential copying or abbreviation expansion.
