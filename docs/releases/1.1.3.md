# Clipline 1.1.3

Hover reveal now uses only the MacBook notch's width at the top of the display, detected from its hardware boundaries. Moving across other parts of the menu bar no longer opens the shelf. Displays without a notch use a centered 180-point region at the top.

The existing interaction rules are preserved:

- Hover for about **0.08 seconds** to reveal the shelf.
- After a hover reveal, the shelf stays open throughout the display's **upper third** and closes when the pointer leaves that area.
- Idle new items preview for **3 seconds**. Holding a card, dragging, or using a context menu postpones dismissal.
- After a manual reveal, the shelf closes **5 seconds** after the pointer enters and then leaves it.

The README, installation instructions, release notes, and demo captions are now in English. The 13-second demo demonstrates native file drag and drop into a local browser fixture with no network upload. This English-captioned video reuses the original 1.1.0 recording; it is not a new recording of notch activation.

Verification: all **58 tests passed**, including six notch-region regression tests. A native verification host built from the same 1.1.3 sources was checked with real pointer movement: both sides of the menu bar stayed hidden, the notch center and exact top edge revealed the shelf, movement within the upper third kept it open, and leaving that region retracted it. The universal app signature, DMG, ZIP, and SHA-256 checksums passed validation. Non-notched and secondary-display geometry was covered by automated tests; other physical displays were not exercised.

Requires macOS 14+. Universal app for Apple Silicon and Intel. The shared build uses an ad-hoc signature and is not notarized by Apple. macOS may request screenshot-folder access again after an update; allow it to resume collecting screenshots.

Installers: `Clipline-1.1.3-universal.dmg` and `Clipline-1.1.3-universal.zip`. Checksums: `SHA256SUMS.txt`.
