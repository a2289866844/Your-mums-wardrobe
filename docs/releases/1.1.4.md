# Clipline 1.1.4

Fixes screenshot monitoring getting stuck after an initial folder-access failure. Previously, the app could keep running and collect clipboard items while new screenshots never reached the shelf. The failed directory watcher returned without retrying, so granting access later was not enough to restore it.

- Retry folder attachment or listing while access is unavailable, then stop retrying when monitoring is healthy.
- Reconnect to the configured path after the watched folder is renamed, deleted, or replaced.
- Keep the selected screenshot destination even when it is temporarily unavailable, instead of silently switching the watcher to Desktop.
- Preserve the startup cutoff while waiting for access, so captures taken during that wait remain eligible. Old images are not replayed as new captures, and accepted files are not repeatedly delivered.
- Cancel pending recovery when monitoring stops.

The notch hover region and three-second new-item preview remain unchanged.

Verification: all **65 automated tests passed**, including seven new watcher-recovery tests. The failure was reproduced on the installed 1.1.3 app: a native macOS screenshot reached the configured folder while the app had no directory-watch descriptor and did not collect it. Restarting that same app restored collection. After installing 1.1.4, two native macOS captures reached the shelf in approximately 0.34 and 0.33 seconds in this local run. Screen captures confirmed the actual overlay visible before one second and hidden after four seconds for both runs. These observations cover this Mac and save location; they are not a timing guarantee for every system. Permission-denial recovery was exercised with controlled failures in the tests, without revoking the user's macOS permissions. The universal app signature, DMG, ZIP, and SHA-256 checksums passed validation.

Requires macOS 14+. Universal app for Apple Silicon and Intel. The shared build uses an ad-hoc signature and is not notarized by Apple. macOS may request screenshot-folder access again after an update.

Installers: `Clipline-1.1.4-universal.dmg` and `Clipline-1.1.4-universal.zip`. Checksums: `SHA256SUMS.txt`.
