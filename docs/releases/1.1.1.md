# Clipline 1.1.1

修正截圖存到桌面後，沒有出現在 Clipline 的問題。

部分 macOS 截圖沒有 `kMDItemIsScreenCapture` 延伸屬性，而是把 `Screenshot` 標記寫在圖片的 EXIF UserComment。1.1.0 的桌面過濾只檢查前者，因此漏掉這類正常截圖；1.1.1 同時辨識兩種標記，一般桌面圖片仍不會自動加入。

新圖片的標記若稍晚才寫入，會短暫重試辨識；未完成的截圖也會監看屬性變更。重試有上限，避免一般圖片造成持續輪詢。

另補充 macOS 浮動縮圖的等待說明：開啟原生縮圖時，截圖可能延後數秒才寫入磁碟，Clipline 要等檔案出現才能接收。可在 Command + Shift + 5 → 選項取消「顯示浮動縮圖」，保留原儲存位置；或使用 Clipline 的 Handle screenshots。1.1.1 不會擅自改動此系統設定。

驗證：全部 47 項測試通過，包含 5 項新的桌面截圖辨識測試。已在安裝後的正式 App 驗證：相同 macOS 原生截圖方式，舊版未加入、新版成功加入桌面截圖。關閉原生縮圖後，一次本機實測從原生截圖指令開始到加入浮層約 0.35 秒，亦擷取到新卡片的出現動畫；這是單次觀測，並非所有機器的效能保證。先前專用資料夾示範未覆蓋此桌面過濾情境。

適用於 macOS 14+，包含 Apple Silicon / Intel。分享版仍採 ad-hoc 簽章，未經 Apple 公證。

安裝包：`Clipline-1.1.1-universal.dmg`、`Clipline-1.1.1-universal.zip`。校驗檔：`SHA256SUMS.txt`。
