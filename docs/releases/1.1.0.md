# Clipline 1.1.0

Clipline 的浮層現在可暫存新截圖，以及新複製的圖片、純文字、HTTP(S) 連結與檔案參照。這些是支援的內容類型，不代表保留所有 App 的每種剪貼簿格式。

- 單擊卡片開啟；右鍵選 Copy 複製。拖曳時，圖片與檔案以檔案傳遞，文字保留全文，連結以 URL 傳遞。長按 Markup 僅適用於圖片。
- 卡片高度一致，圖片保留比例完整顯示。依螢幕寬度提供 3–12 個位置，滿載時最舊卡片掉落，屬於有限容量的暫存架。
- 內容在本機保存並於重啟後還原。剪貼簿產生的副本存於 `~/Library/Application Support/Clipline/Clipboard`；外部檔案參照移除卡片時保留原檔案。
- 新內容無人操作時預覽 3 秒；按住、拖曳或右鍵選單操作期間延後收起。滑鼠召喚後在螢幕頂部三分之一保持顯示；手動召喚後，滑鼠離開浮層 5 秒收起。
- **Hang copied items** 預設開啟，可在選單列關閉以暫停收集。帶有受保護剪貼簿標記的內容會被略過；無法辨識所有機密資料，複製敏感內容前可先暫停。

本次通過 42 項自動測試。macOS 14+ 的 Apple Silicon / Intel 通用安裝包已檢查雙架構、簽章、DMG / ZIP 完整性與 SHA-256 校驗。App 使用 ad-hoc 簽章，未經 Apple 公證。

已完成原生截圖 → Clipline 浮層 → Chrome 本機聊天輸入框的實際檔案拖放，目的地顯示圖片預覽與「Screenshot attached」。13 秒示範使用相同 App 原始碼及獨立儲存資料夾的驗證版；聊天畫面是合成的本機測試場景，沒有網路上傳，未驗證真正 ChatGPT 的接收操作。

安裝檔：`Clipline-1.1.0-universal.dmg`、`Clipline-1.1.0-universal.zip`。校驗檔：`SHA256SUMS.txt`。問題回報：[GitHub Issues](https://github.com/a2289866844/clipline/issues)。
