# Clipline 1.1.0

The Clipline shelf now holds new screenshots and newly copied images, plain text, HTTP(S) links, and file references. These content types are supported; not every clipboard format from every app is preserved.

- Click a card to open it; right-click and choose Copy to copy it. Dragging delivers images and files as files, preserves the full text, and delivers links as URLs. Press-and-hold Markup is available only for images.
- Cards have a consistent height and show entire images with their aspect ratio preserved. The shelf has 3–12 slots, depending on screen width; the oldest card drops off when full.
- Contents are saved locally and restored after restarting. Clipboard-generated copies are stored in `~/Library/Application Support/Clipline/Clipboard`. Removing an external file reference from the shelf preserves its original file.
- Idle new items preview for 3 seconds; holding a card, dragging, or using a context menu postpones dismissal. After a hover reveal, the shelf stays open throughout the display's upper third. After a manual reveal, it closes 5 seconds after the pointer leaves the shelf.
- **Hang copied items** is enabled by default and can be disabled in the menu bar to pause collection. Content with protected clipboard markers is skipped. Clipline cannot identify every confidential item; pause collection before copying sensitive content.

All 42 automated tests passed for this release. The macOS 14+ universal installer for Apple Silicon and Intel was checked for both architectures, signing, DMG / ZIP integrity, and SHA-256 checksums. The app uses an ad-hoc signature and is not notarized by Apple.

An actual native file drag was completed from a macOS screenshot through the Clipline shelf into a local chat composer in Chrome. The destination displayed an image preview and “Screenshot attached.” The 13-second demo uses a verification build compiled from the same app sources with separate storage folders. The chat scene is a synthetic local test fixture with no network upload; receiving a file in a real ChatGPT conversation was not verified.
