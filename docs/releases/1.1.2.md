# Clipline 1.1.2

Adds a Desktop screenshot folder. During initial setup, if macOS saves screenshots directly to Desktop, Clipline creates **Desktop/Screenshots** and directs new screenshots there to keep Desktop tidy. On Chinese-language systems, the folder is named **截圖**.

- Existing custom locations are preserved, including destinations that are temporarily unavailable. Later manual changes back to Desktop or another location are not overwritten.
- The save location remains after quitting Clipline. If the managed folder currently in use is removed, it is recreated on the next launch.
- Old screenshots are not moved. This folder is separate from the private **Handle screenshots** inbox; removing its cards or evicting them when the shelf is full does not delete the original files.
- The existing macOS floating-thumbnail setting is preserved. For prompt display, disable **Show Floating Thumbnail** under **Command + Shift + 5 → Options**.

All 52 automated tests passed, covering folder-creation failure, existing custom locations, folder recreation, and preservation of old files.

Requires macOS 14+. Universal app for Apple Silicon and Intel. The shared build uses an ad-hoc signature and is not notarized by Apple.
