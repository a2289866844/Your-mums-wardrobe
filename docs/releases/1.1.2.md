# Clipline 1.1.2

新增桌面截圖資料夾：首次設定時，若 macOS 原本把截圖存到桌面，Clipline 會自動建立「桌面／截圖」（非中文系統為 Screenshots），讓之後的截圖直接存入，保持桌面整齊。

- 已有自訂儲存位置會沿用，包括暫時不存在的目的地；之後手動改回桌面或其他位置也不會被覆寫。
- 退出 Clipline 後仍保留這個儲存位置；若正在使用的受管理資料夾被移除，下次啟動會重新建立。
- 舊截圖不搬動。這個資料夾與私有的 Handle screenshots 收件匣分開，從浮層移除卡片或容量淘汰不會刪除這裡的原檔案。
- 沿用原本的 macOS 浮動縮圖設定。若需要立即顯示，可在 Command + Shift + 5 → 選項取消「顯示浮動縮圖」。

全部 52 項自動測試通過，涵蓋資料夾建立失敗、既有自訂位置、資料夾重新建立及保留舊檔案。

macOS 14+，Apple Silicon / Intel 通用版。分享版採 ad-hoc 簽章，未經 Apple 公證。
