# Clipline 1.0.1

Clipline is a personal customized build based on Tendedero 1.0.0. It preserves the original author's attribution and the MIT source-code license, with an independent name and new icon.

## Download and install

- **DMG**: open it and drag Clipline.app to Applications. Suitable for sharing directly with friends.
- **ZIP**: extract it and place Clipline.app in Applications.
- Requires macOS 14 or later. The same app includes both Apple Silicon and Intel architectures.
- The shared build uses an ad-hoc signature and **is not notarized by Apple**. If macOS blocks it, follow [Apple's instructions](https://support.apple.com/guide/mac-help/mh40616/mac): **System Settings → Privacy & Security → Open Anyway**.

## Shelf behavior

- Hover in the reveal region for about 0.08 seconds to open the shelf. Cards are larger and the opening animation is faster.
- After a hover reveal, the shelf stays open throughout the display's upper third and closes when the pointer leaves that area.
- New screenshots preview for a fixed 3 seconds. Each new screenshot restarts the timer.
- Reveal manually using Control + Option + T or the menu. After the pointer enters and then leaves the shelf, it closes 5 seconds later.
- Switching apps or Spaces does not reset the timer. Full-screen Spaces are supported.
- Fixes cover repeated opening and closing at the boundary, new screenshots failing to reveal a full shelf, truncated lists after restarting, and images being permanently missed before they finish writing.

Clipline uses separate preferences and `~/Library/Application Support/Clipline/Screenshots`. On first launch, you choose whether it manages your screenshot location. Avoid having Clipline and another screenshot manager control macOS screenshot settings at the same time. In managed mode, clicking the cross on an image sends its file to Trash.

## Verification

All **16 regression tests passed with zero failures** on macOS 26.5.1 / Swift 6.3.3. The arm64 and x86_64 release builds passed. The universal app, signature, mounted DMG contents, ZIP contents, and SHA-256 checksums were checked successfully. The app was launched and its new name, icon, and first-launch prompt were inspected. Manual testing did not cover every combination of full-screen apps, multiple displays, and pointer interactions. The app was not run on Intel hardware.
