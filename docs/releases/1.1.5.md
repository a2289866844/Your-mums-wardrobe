# Clipline 1.1.5

Image cards open in macOS **Preview** and center the matching document window on the display where you clicked, keeping its current size. Enable **System Settings → Privacy & Security → Accessibility → Clipline**, then click the image again. Without permission, the image still opens normally.

This release also includes the fixes from the comprehensive 1.1.4 code review:

- Guard clipboard reads against protected-content races, preserve original file references, and keep copied image files available until the clipboard changes.
- Bound unfinished screenshot watches, handle sustained folder activity and file/folder replacement, and follow screenshot-location changes while the app is running.
- Restore screenshot settings individually so newer user choices are preserved, including recovery after failed inbox setup.
- Protect active Markup sessions and files, reject stale callbacks, and write the correct image format and orientation.
- Fix shelf capacity and layout, card hit regions, delayed drag callbacks, and moving animation targets.
- Cache unchanged image digests, reuse screenshot metadata, limit text reads, skip hidden animation work, and remove unused private window APIs.

**Validation:** all **130 automated tests passed**. The universal arm64/x86_64 app, signature, DMG, ZIP, and SHA-256 checksums passed validation. Native Preview centering was verified on this Mac using the same application sources, with a synthetic image and the reported screenshot, including after restarting Clipline; success requires reading back the expected position and unchanged window size. Multiple-display coordinates are covered by tests; physical multiple-display and Intel execution were not repeated. Actual Markup-extension, Finder-paste, and external drag-and-drop workflows remain outside this round's end-to-end acceptance.

Details: [code review and performance measurements](https://github.com/a2289866844/clipline/blob/personal/docs/reviews/clipline-1.1.4-code-review.md) and [Preview centering acceptance](https://github.com/a2289866844/clipline/blob/personal/docs/reviews/preview-window-centering.md).

Requires macOS 14+. Universal app for Apple Silicon and Intel. The shared build uses an ad-hoc signature and is not notarized by Apple. An update may request screenshot-folder or Accessibility access again.

Installers: `Clipline-1.1.5-universal.dmg` and `Clipline-1.1.5-universal.zip`. Checksums: `SHA256SUMS.txt`.
